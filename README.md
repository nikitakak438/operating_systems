# Lab_2 (Linux) — “Волк и козлята” (1 к 1, независимые процессы)

## Вариант
- Сценарий: **1** (“Волк и семеро козлят”, в конфигурации 1 к 1 фактически n = 1)
- Конфигурация: **Независимые процессы, один к одному**
- Handshake: **клиент отправляет SIGUSR1 хосту**
- Синхронизация: **глобальные POSIX семафоры (sem_open)**, все ожидания с таймаутом **5 секунд**
- Реализованные IPC (по варианту):
  - `seg` — System V shared memory (`shmget/shmat/...`)
  - `mq` — POSIX message queue (`mq_open/...`)
  - `fifo` — Named pipe (`mkfifo/open/read/write`)
